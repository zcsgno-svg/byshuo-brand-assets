# Byshuo Brand Assets

This repository stores approved brand files and working source materials for Byshuo.

## Directory structure

- `logo/svg/` — vector logo exports
- `logo/png/` — raster logo exports
- `source/` — editable source files
- `guidelines/` — usage and export guidance
- `archive/` — retired assets retained for reference

Add a short description, original source, and relevant dimensions when introducing an asset. Keep final exports in the matching format directory and move superseded versions to `archive/`.
